# NINE — Capsule Wardrobe

**적게 소유하고, 더 잘 입기.** 작은 옷장에서 나다운 가능성을 찾는 모바일 우선 캡슐 옷장.

- 웹앱: https://nine-capsule.vercel.app
- GitHub: https://github.com/designlogg/nine-capsule

## 실행

Node.js 20.19+ 또는 22.12+ 권장.

```sh
npm install
npm run dev
npm test
npm run build
```

Vercel: Framework `Vite`, Build `npm run build`, Output `dist`. 저장소 루트를 프로젝트 루트로 설정합니다. API 키·환경변수·백엔드가 필요하지 않습니다.

## 구현된 MVP

- 3×3 캡슐: 상의 6 / 하의 3 고정 분류, 탭 선택, 교체·빈 슬롯 추가, 편집 모드에서 같은 분류 간 드래그 교환
- 계절별 새 보드, 여러 보드 저장·복제·전환·시즌 비교, KEEP 및 계절 필터를 이용한 규칙 기반 구성
- 2개 자유 조합과 3개 직선 경로 검증. 3개는 base + over + 하의만 허용. 상의 3개, 동일 레이어 2개 제외
- 의류 상세에서 함께 입지 않는 아이템 지정. 이 규칙을 기본 조합과 레이어링 후보 모두에 적용. 샘플은 16개 기본 조합, 3개 경로
- 코디 미리보기·저장·삭제, 액세서리 연결 및 착용 기록
- 옷장 등록·수정·삭제, 사진 업로드(최대 15MB, 900px JPEG로 축소), 분류 및 이름 검색
- KEEP / REVIEW / ARCHIVE / WISHLIST, 소재·브랜드·가격·구매일·위치·메모, 착용·세탁·수선·보관 기록, 회당 착용 비용
- 이미지 기반 추구미 선택, 색상·핏·상황 프로필
- 여행지·날짜·목적·활동·예상 날씨·캐리어 입력, 여행 보드, 최대 60일 재착용 코디 계획 및 날짜별 교체
- 캡슐별 패킹 체크, 필수 소지품 및 직접 항목 추가, 진행률
- localStorage 자동 저장, JSON 백업/복원, 데모 초기화, 빈 상태 및 오류 피드백
- 모바일 바텀 내비게이션, 바텀시트, 키보드 포커스·Escape·포커스 트랩·reduced motion

## 사용자 흐름

1. 샘플 캡슐에서 조합을 선택 → 프리뷰 → 스타일링 키트 선택 → 저장
2. CLOSET → 의류 등록 → 이미지와 최소 정보 입력 → 캡슐 편집 → 의류 교체
3. 새 캡슐 → 계절 선택 → 보유 의류 구성 → 빈 슬롯 채우기
4. 여행 캡슐 → 여행 정보 입력 → 보드 생성 → 날짜별 구성 → 패킹 체크
5. MY → 추구미 다시 찾기 → 스타일·색상·핏·상황 저장 → 착용 인사이트 확인

## 구조

- `src/main.jsx`: 앱 상태, 내비게이션, 캡슐·옷장·MY 화면
- `src/Forms.jsx`: 의류 편집, 추구미 프로필, 여행 일정·패킹
- `src/Garment.jsx`: 재사용 가능한 SVG 의류 일러스트 및 사용자 업로드 렌더러
- `src/logic.js`: 분류 규칙, 직선 경로, 조합 검증, 규칙 기반 구성
- `src/data.js`: 버전이 있는 초기 데이터 및 데모
- `src/logic.test.js`: 핵심 조합 규칙 테스트
- `src/styles.css`: 디자인 토큰 및 반응형 레이아웃

## 데이터 및 한계

데이터는 현재 기기·브라우저의 `nine-v1` localStorage에만 저장됩니다. 이미지도 로컬 저장되며 서버로 업로드되지 않습니다. 용량 초과 시 오류를 알립니다. 데이터 유지가 필요하면 MY에서 백업하세요. 시크릿 모드·브라우저 데이터 삭제·기기 변경 시 별도 복원이 필요합니다.

레이어링은 사용자가 지정한 base/over와 제외 조합으로 판단하는 규칙 기반 기능입니다. 소재 두께, 실제 핏, 색상 조화 등을 AI가 평가하지 않습니다. 16개 후보가 모두 실제 착용에 적합하다는 보장은 없으며, 사용자가 제외 조합을 관리할 수 있습니다. 프로필은 저장되지만 자동 구성은 계절과 KEEP만 사용합니다. 날씨는 수동 입력이며 일정 생성에 자동 예보를 반영하지 않습니다.

데모 옷은 자체 SVG 일러스트. 저널 및 분위기 참고 이미지는 Unsplash 원격 URL, Pretendard는 jsDelivr로 제공됩니다. 외부 이미지와 폰트는 네트워크가 필요합니다. AI·계정·클라우드 동기화·PWA 오프라인 기능은 구현되어 있지 않습니다.
